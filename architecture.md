# Architecture

## Overview
- Static website project for ITB Nigeria.
- Primary pages are HTML files in repo root.
- Styling and behavior are embedded and/or linked in existing page templates.

## Careers Page
- Careers content is rendered from [careers.html](careers.html).
- Vacancy messaging is maintained as inline text blocks in the page markup.

## Deployment
- Packaging and deployment helper scripts exist in repo root (PowerShell).
