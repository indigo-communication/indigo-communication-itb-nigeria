TROUBLESHOOTING
---------------
If images don't load:
- Check that images folder was extracted correctly
- Verify file permissions (755 for directories, 644 for files)

If contact form doesn't work:
- Verify contact_handler.php has correct permissions
- Check PHP is enabled on your hosting plan
- Update email address in contact_handler.php if needed

If pages show 404 errors:
- Verify all HTML files are in public_html root
- Check .htaccess file is present
- Ensure mod_rewrite is enabled on server

CONTACT FORM CONFIGURATION
---------------------------
To configure the contact form email recipient:
1. Open contact_handler.php in File Manager editor
2. Find the line: $to = "your-email@example.com";
3. Replace with your actual email address
4. Save the file
